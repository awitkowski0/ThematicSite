# Play Thematic

The fastest way to get {{suitCount}} superhero suits into your game is the official modpack — no manual dependency-chasing required.

## Install via Modrinth

1. Get the [Modrinth App](https://modrinth.com/app) if you don't already have it.
2. Install the [Superhero Modpack](https://modrinth.com/modpack/superhero-modpack) — it bundles Thematic with Fabric API and everything else it needs.
3. Launch it and you're in.

## Join the official server

Thematic has an official multiplayer server at:

```
thematic.bond
```

Add it in Minecraft's multiplayer menu, or click "Official Server" in-game. It's running the same modpack, so anything you install through Modrinth will work there directly.

# How to join

The quickest way to play is the official modpack. It installs Thematic, Fabric API and everything else it needs.

## Install the modpack

1. Get the [Modrinth App](https://modrinth.com/app).
2. Install the [Superhero Modpack](https://modrinth.com/modpack/superhero-modpack).
3. Launch it.

Playing your own setup instead? Thematic is on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/thematic-superheroes) and [Modrinth](https://modrinth.com/mod/thematic-superheroes) for Fabric on Minecraft 1.20.1, and needs [Fabric API](https://modrinth.com/mod/fabric-api).

## Join the official server

```
thematic.bond
```

Add it in the multiplayer menu, or click **Official Server** in game. The server runs the same modpack, so the install above works there as is.
